# 七、安全与认证系统

CountBot 的安全系统采用"零配置"设计理念：本地使用无需任何设置，远程访问自动启用保护。

## 1、安全模型概览

```
┌────────────────────────────────────────────────┐
│               安全分级模型                       │
│                                                 │
│  ┌──────────────────────────────────────────┐   │
│  │ 本地直连 (127.0.0.1, 无代理头)            │   │
│  │ → 直接放行，无需认证                       │   │
│  └──────────────────────────────────────────┘   │
│                                                 │
│  ┌──────────────────────────────────────────┐   │
│  │ 反向代理后 (socket IP = 127.0.0.1, 有代理头)│   │
│  │ → 不信任 socket IP，要求认证               │   │
│  └──────────────────────────────────────────┘   │
│                                                 │
│  ┌──────────────────────────────────────────┐   │
│  │ 远程访问 (192.168.x.x 等)                 │   │
│  │ → 首次访问：提示设置密码                    │   │
│  │ → 后续访问：JWT token 验证                  │   │
│  └──────────────────────────────────────────┘   │
└────────────────────────────────────────────────┘
```

## 2、RemoteAuthMiddleware（认证中间件）

核心文件：`backend/modules/auth/middleware.py`

### （1）安全判断核心逻辑

```python
# middleware.py:150-206
class RemoteAuthMiddleware(BaseHTTPMiddleware):

    async def dispatch(self, request, call_next):
        path = request.url.path

        # 1. 只拦截 API 和 WebSocket 路径
        if not path.startswith("/api/") and not path.startswith("/ws/"):
            return await call_next(request)  # 静态资源全部放行

        # 2. 白名单路径放行
        if _is_whitelisted(path):
            return await call_next(request)  # /api/auth/, /api/health 等

        # 3. TCP 层面判断本地请求
        is_local = _is_local_request(request)
        if is_local:
            return await call_next(request)  # 本地直接放行

        # 4. 远程请求 - 检查密码
        password_hash = await self._get_password_hash_safe()
        if not password_hash:
            return await call_next(request)  # 未设密码也放行（前端显示警告）

        # 5. 检查 session token
        token = _get_token_from_request(request)
        username = validate_session(token) if token else None
        if username:
            return await call_next(request)  # 认证通过

        # 6. 未认证 → 401
        return JSONResponse(status_code=401, content={...})
```

### （2）TCP 层面的本地请求判断

这是安全系统最关键的设计，位于 middleware.py:89-126：

```python
def _is_local_request(request):
    """TCP 层面判断是否为本地请求"""

    # 1. 获取 TCP socket 层的 IP（操作系统提供，无法伪造）
    client_ip = request.client.host

    # 2. 检测是否有代理头
    if _has_proxy_headers(request):
        # 有代理头 = 在反向代理后面
        # socket IP 是代理 IP（可能是 127.0.0.1），不可信
        return False

    # 3. 无代理头 = 直接连接，socket IP 可信
    return client_ip in {"127.0.0.1", "::1"}
```

为什么这个设计是安全的？

```
场景 1：用户在本地直接访问
  socket IP = 127.0.0.1, 无代理头
  → 判定为本地，放行 ✓

场景 2：用户通过 Nginx 反向代理访问
  socket IP = 127.0.0.1（Nginx 到后端的连接）
  但有 X-Forwarded-For 等代理头
  → 检测到代理，判定为远程，要求认证 ✓

场景 3：攻击者尝试伪造代理头绕过
  攻击者直接连接，socket IP = 攻击者 IP
  即使添加代理头，socket IP 也不是 127.0.0.1
  → 判定为远程，要求认证 ✓

场景 4：攻击者通过代理尝试访问
  经过代理，有代理头
  → 检测到代理，要求认证 ✓
```

### （3）代理头检测

```python
# middleware.py:39-51
PROXY_HEADERS = {
    "x-forwarded-for",
    "x-real-ip",
    "x-forwarded-host",
    "x-forwarded-proto",
    "forwarded",
    "via",
    "x-forwarded-server",
    "x-cluster-client-ip",
    "cf-connecting-ip",      # Cloudflare
    "true-client-ip",        # Cloudflare
}

def _has_proxy_headers(request):
    request_headers = {k.lower() for k in request.headers.keys()}
    return bool(PROXY_HEADERS & request_headers)  # 集合交集
```

### （5）Token 提取

```python
# middleware.py:137-147
def _get_token_from_request(request):
    # 优先从 Cookie 获取
    token = request.cookies.get("CountBot_token")
    if token:
        return token
    # 其次从 Authorization header 获取
    auth_header = request.headers.get("authorization", "")
    if auth_header.startswith("Bearer "):
        return auth_header[7:]
    return None
```

## 3、WebSocket 认证

WebSocket 连接的认证在 `backend/app.py:392-433` 中处理，逻辑与 HTTP 中间件一致：

```python
# 1. TCP 层获取真实客户端 IP
client_ip = websocket.client.host

# 2. 检测代理头
proxy_headers = {"x-forwarded-for", "x-real-ip", ...}
has_proxy = bool(proxy_headers & request_headers)

# 3. 判断是否本地
is_local = client_ip in LOCAL_IPS and not has_proxy

# 4. 远程连接需要验证 token
if not is_local:
    token = websocket.query_params.get("token") or websocket.cookies.get("CountBot_token")
    if not token or not validate_ws_session(token):
        await websocket.close(code=4001, reason="Authentication required")
        return
```

## 4、认证路由

核心文件：`backend/modules/auth/router.py`

### （1）密码设置流程

```
首次远程访问
    │
    ▼ 前端检测到未设置密码 → 显示设置密码页面
    │
    ▼ POST /api/auth/set-password
    │  body: { password: "MyPassword123" }
    │
    ▼ 验证密码强度（8+ 字符，大小写 + 数字）
    │
    ▼ bcrypt 哈希后存入 Setting 表
    │
    ▼ 返回 session token
```

### （2）登录流程

```
远程访问 → 401 → 重定向到 /login
    │
    ▼ POST /api/auth/login
    │  body: { password: "MyPassword123" }
    │
    ▼ bcrypt 验证密码
    │
    ▼ 生成 session token（JWT 或自定义）
    │
    ▼ 设置 Cookie: CountBot_token=xxx
    │
    ▼ 返回成功
```

## 5、工具安全机制

### （1）Shell 工具安全

```python
# tools/shell.py 中的安全特性

# 危险命令拦截模式
DANGEROUS_PATTERNS = [
    r"rm\s+-rf\s+/",        # rm -rf /
    r"format\s+",            # format
    r"mkfs\.",               # mkfs.ext4 等
    r"dd\s+if=",             # dd 直接写磁盘
    # ... 更多模式
]

# 执行安全检查
def _check_command_safety(self, command):
    # 1. 检查黑名单模式
    for pattern in self.deny_patterns:
        if re.search(pattern, command, re.IGNORECASE):
            raise ValueError(f"Dangerous command blocked")

    # 2. 如果启用白名单，只允许白名单中的命令
    if self.allow_patterns:
        allowed = any(re.search(p, command) for p in self.allow_patterns)
        if not allowed:
            raise ValueError(f"Command not in whitelist")
```

## 7、设计要点总结

（1）**零配置安全**：本地使用完全不需要任何配置，开箱即用
（2）**TCP 层验证**：不依赖 HTTP 头判断来源，使用操作系统提供的 socket IP
（3）**代理感知**：正确处理反向代理场景，不会被绕过
（4）**渐进式保护**：未设密码时给警告但不阻止，设置密码后强制认证
（5）**多层防御**：认证中间件 + 工具安全 + 提示词约束 + 审计日志
