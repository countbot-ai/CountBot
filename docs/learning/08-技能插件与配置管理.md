# 八、技能插件与配置管理

技能系统是 CountBot 的可扩展能力层，配置系统管理所有运行参数。

## 1、技能系统架构

```
skills/                          # 技能目录
├── weather/                     # 天气技能（示例）
│   ├── SKILL.md                # ★ 技能描述文件（必须）
│   └── manifest.json           # ★ 技能清单（必须）
├── email/
│   ├── SKILL.md
│   └── manifest.json
├── baidu-search/
│   ├── SKILL.md
│   └── manifest.json
└── ...
```

## 2、技能清单（manifest.json）

每个技能目录下必须有一个 `manifest.json`，定义技能的元数据：

```json
{
    "name": "weather",
    "display_name": "天气查询",
    "description": "查询全球天气信息",
    "version": "1.0.0",
    "author": "CountBot",
    "always": false,
    "enabled": true,
    "tags": ["weather", "utility"]
}
```

关键字段：
- `name`：技能唯一标识
- `always`：是否总是加载到系统提示词中（`true` = 自动加载，`false` = 按需加载）
- `enabled`：是否启用

## 3、技能描述文件（SKILL.md）

SKILL.md 是技能的核心内容，会被加载到 LLM 的上下文中。它通常包含：

```markdown
# 天气查询技能

## 功能
查询指定城市的天气信息

## 使用方法
1. 使用 web_fetch 工具访问 wttr.in API
2. 解析返回的天气数据
3. 格式化输出给用户

## API 信息
- 基础 URL: https://wttr.in/{城市名}?format=j1
- 无需认证
- 返回 JSON 格式

## 注意事项
- 城市名使用英文
- 支持中文城市名的拼音
```

## 4、SkillsLoader（技能加载器）

核心文件：`backend/modules/agent/skills.py`

### （1）技能加载机制

```python
class SkillsLoader:
    def __init__(self, skills_dir):
        self.skills_dir = skills_dir
        self._manifests = {}  # {name: manifest}
        self._load_manifests()

    def _load_manifests(self):
        """扫描技能目录，加载所有 manifest.json"""
        for skill_dir in self.skills_dir.iterdir():
            manifest_file = skill_dir / "manifest.json"
            if manifest_file.exists():
                manifest = json.loads(manifest_file.read_text())
                self._manifests[manifest["name"]] = manifest
```

### （2）技能分类

```python
def get_always_skills(self):
    """获取需要自动加载的技能（always=true）"""
    return [
        name for name, m in self._manifests.items()
        if m.get("always") and m.get("enabled", True)
    ]

def get_available_skills(self):
    """获取所有可用技能"""
    return [
        name for name, m in self._manifests.items()
        if m.get("enabled", True)
    ]
```

### （3）技能内容加载

```python
def load_skills_for_context(self, skill_names):
    """加载指定技能的 SKILL.md 内容"""
    contents = []
    for name in skill_names:
        skill_file = self.skills_dir / name / "SKILL.md"
        if skill_file.exists():
            contents.append(skill_file.read_text())
    return "\n\n---\n\n".join(contents)
```

### （4）技能摘要生成

```python
def build_skills_summary(self):
    """生成可用技能的简要列表（嵌入到系统提示词中）"""
    lines = []
    for name, m in self._manifests.items():
        if m.get("enabled", True) and not m.get("always"):
            lines.append(f"- {name}: {m.get('description', '')}")
    return "\n".join(lines)
```

## 5、技能在上下文中的集成

在 ContextBuilder 中，技能被这样集成到系统提示词中：

```python
# context.py:40-60
def build_system_prompt(self):
    parts = []
    parts.append(self._get_identity())

    if self.skills:
        # always 技能：直接加载完整内容到提示词
        always_skills = self.skills.get_always_skills()
        if always_skills:
            content = self.skills.load_skills_for_context(always_skills)
            parts.append(f"# 已激活技能\n\n{content}")

        # 按需技能：只提供摘要，AI 需要时通过 read_file 加载
        summary = self.skills.build_skills_summary()
        if summary:
            parts.append(f"""# 可用技能
以下技能已启用，需要时使用 read_file 工具读取完整内容：
{summary}
**使用方法**: read_file(path='skills/<技能名>/SKILL.md')""")
```

这种**分层加载策略**的好处：
- `always` 技能始终在上下文中，AI 可以直接使用
- 按需技能只占用摘要的少量 token，需要时再加载完整内容
- 避免上下文过长导致 LLM 性能下降

### （1）配置结构（Pydantic 模型）

```python
# schema.py 中的配置层级
class AppConfig:
    model: ModelConfig           # 模型配置
    workspace: WorkspaceConfig   # 工作区配置
    persona: PersonaConfig       # 人设配置
    security: SecurityConfig     # 安全配置
    channels: ChannelsConfig     # 渠道配置
    providers: dict              # LLM 提供商配置

class ModelConfig:
    provider: str = "zhipu"          # 提供商 ID
    model: str = "glm-4-flash"       # 模型名称
    temperature: float = 0.7         # 生成温度
    max_tokens: int = 4096           # 最大 token
    max_iterations: int = 25         # Agent 最大迭代数

class PersonaConfig:
    ai_name: str = "小C"             # AI 名称
    user_name: str = "用户"           # 用户称呼
    user_address: str = ""            # 用户地址
    personality: str = "professional" # 性格 ID
    custom_personality: str = ""      # 自定义性格文本
    max_history_messages: int = 50    # 最大历史消息数
    heartbeat: HeartbeatConfig        # 心跳配置

class HeartbeatConfig:
    enabled: bool = False             # 是否启用
    schedule: str = "0 * * * *"       # cron 表达式
    channel: str = ""                 # 投递渠道
    chat_id: str = ""                 # 投递聊天 ID
    idle_threshold_hours: int = 4     # 空闲阈值（小时）
    quiet_start: int = 21             # 免打扰开始
    quiet_end: int = 8                # 免打扰结束
    max_greets_per_day: int = 2       # 每日最多问候
```

### （2）配置加载流程

```python
# loader.py
```

### （3）配置来源优先级

```
1. 数据库 Setting 表 （最高优先级）
    ↓
2. 环境变量
    ↓
3. 默认值（Pydantic 模型定义）
```

### （4）配置热重载

前端修改配置后，通过 API 调用触发热重载：

```
PUT /api/settings/model
    │
    ▼
config_loader.update_field("model", new_config)
    │
    ▼
message_handler.reload_config(model=new_model, ...)
    │
    ▼
agent_loop.model = new_model  # 立即生效
```

## 9、如何开发自定义技能

步骤 1：创建技能目录

```
skills/my-skill/
├── manifest.json
└── SKILL.md
```

步骤 2：编写 manifest.json

```json
{
    "name": "my-skill",
    "display_name": "我的技能",
    "description": "这个技能的简要描述",
    "version": "1.0.0",
    "always": false,
    "enabled": true
}
```

步骤 3：编写 SKILL.md

```markdown
# 我的技能

## 功能描述
详细描述这个技能能做什么

## 使用方法
告诉 AI 如何使用这个技能

## API 信息（如果有）
描述需要调用的 API

## 示例
给出使用示例
```

步骤 4：重启服务或通过 API 重新加载技能
