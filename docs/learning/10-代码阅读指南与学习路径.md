# 十、代码阅读指南与学习路径

本章提供按模块的逐文件阅读顺序，帮助你系统性地读懂整个项目的代码。

## 1、推荐学习路径

```
阶段一：了解全貌（1-2小时）
  ├── 阅读 01-项目总览与架构设计.md
  ├── 运行项目（python start_dev.py）
  └── 在浏览器中体验基本功能

阶段二：理解启动流程（2-3小时）
  ├── 阅读 02-应用启动与生命周期.md
  └── 逐行阅读 backend/app.py

阶段三：掌握核心引擎（3-4小时）
  ├── 阅读 03-Agent核心系统.md
  ├── 阅读 backend/modules/agent/loop.py
  ├── 阅读 backend/modules/agent/context.py
  └── 阅读 backend/modules/agent/memory.py

阶段四：理解工具系统（2-3小时）
  ├── 阅读 04-工具系统设计.md
  ├── 阅读 backend/modules/tools/base.py
  ├── 阅读 backend/modules/tools/registry.py
  └── 选读几个具体工具实现

阶段五：理解多渠道（2-3小时）
  ├── 阅读 05-渠道与消息系统.md
  ├── 阅读 backend/modules/channels/ 目录
  └── 阅读 backend/modules/messaging/ 目录

阶段六：补充系统（3-4小时）
  ├── 阅读 06-10 章的文档
  └── 对应代码
```

## 5、调试与学习技巧

### （1）**日志是最好的老师**

启动开发模式后，观察 loguru 的输出：
```bash
python start_dev.py
```
日志会清晰地展示每个组件的初始化和消息处理流程。

### （2）**从 API 入手**

使用浏览器访问 `http://localhost:8000/docs` 查看 OpenAPI 文档，逐个尝试 API。

### （3）**断点调试**

在 VS Code 中配置 Python 调试，在以下关键位置设置断点：
- `agent/loop.py:112` — LLM 调用前
- `agent/loop.py:216` — 工具执行前
- `channels/handler.py:187` — 消息处理入口
- `auth/middleware.py:157` — 认证检查入口

### （4）**数据库查看**

使用 SQLite 客户端直接查看数据库：
```bash
sqlite3 ~/.countbot/data/countbot.db
.tables
SELECT * FROM sessions LIMIT 5;
SELECT * FROM messages WHERE session_id = 'xxx' ORDER BY created_at;
```

### （5）**记忆文件查看**

直接打开记忆文件了解 AI 记住了什么：
```bash
cat ~/.countbot/workspace/memory/MEMORY.md
```
