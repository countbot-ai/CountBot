# 四、工具系统设计

工具系统是 Agent 能力的延伸，让 AI 不仅能对话，还能读写文件、执行命令、访问网页等。位于 `backend/modules/tools/` 目录。

## 2、Tool 基类

核心文件：`backend/modules/tools/base.py`

### （1）抽象接口定义

```python
class Tool(ABC):
    """工具抽象基类 - 所有工具必须继承此类"""

    @property
    @abstractmethod
    def name(self) -> str:
        """工具的唯一名称（如 'read_file'）"""

    @property
    @abstractmethod
    def description(self) -> str:
        """工具描述（供 LLM 理解用途）"""

    @property
    @abstractmethod
    def parameters(self) -> dict:
        """工具参数的 JSON Schema"""

    @abstractmethod
    async def execute(self, **kwargs) -> str:
        """执行工具，返回结果字符串"""
```

每个工具必须实现这四个抽象成员。LLM 通过 `name`、`description` 和 `parameters` 来决定何时以及如何调用工具。

### （3）工具定义生成

```python
# base.py:153-174
def get_definition(self):
    """生成 LLM 函数调用格式的工具定义"""
    return {
        "type": "function",
        "function": {
            "name": self.name,
            "description": self.description,
            "parameters": self.parameters,
        },
    }
```

这个格式符合 OpenAI 的 Function Calling 规范，LiteLLM 会将其转换为各个 LLM 提供商的对应格式。

## 3、ToolRegistry（工具注册表）

核心文件：`backend/modules/tools/registry.py`

### （1）核心职责

ToolRegistry 是工具系统的中央管理器，负责：

- **注册/注销工具**：维护工具名称到实例的映射
- **执行工具**：参数验证 → 执行 → 审计日志 → 错误处理
- **生成定义**：为 LLM 生成所有工具的描述列表
- **会话管理**：设置当前 session_id 和 channel

### （2）工具执行流程

```python
# registry.py:131-244
async def execute(self, tool_name, arguments, auto_record=True):
    # 1. 查找工具
    tool = self.get_tool(tool_name)
    if tool is None:
        return f"Error: Tool '{tool_name}' not found"

    # 2. 生成调用 ID + 记录开始
    call_id = str(uuid.uuid4())
    if self._audit_enabled:
        file_audit_logger.record_call(call_id, tool_name, arguments, self._session_id)

    # 3. 参数验证
    errors = tool.validate_params(arguments)
    if errors:
        return f"Error: Invalid parameters: {'; '.join(errors)}"

    # 4. 执行工具
    try:
        result = await tool.execute(**arguments)
        # 记录成功
        file_audit_logger.update_result(call_id, result, "success", duration_ms)
        return result
    except Exception as e:
        # 记录失败
        file_audit_logger.update_result(call_id, str(e), "error")
        return f"Error executing {tool_name}: {str(e)}"
```

关键设计：**execute 方法永远不会抛出异常**，而是返回错误字符串。这样 Agent 循环可以继续运行，LLM 可以根据错误信息决定下一步操作。

### （3）会话感知

```python
# registry.py:29-49
def set_session_id(self, session_id):
    """设置当前会话 ID"""
    self._session_id = session_id
    # 同步更新需要 session_id 的工具
    send_media_tool = self._tools.get('send_media')
    if send_media_tool:
        send_media_tool.set_session_id(session_id)

def set_channel(self, channel):
    """设置当前消息来源渠道"""
    self._channel = channel
    # 同步更新记忆工具的默认来源
    memory_write_tool = self._tools.get('memory_write')
    if memory_write_tool:
        memory_write_tool.set_channel(channel)
```

## 4、工具注册统一配置

核心文件：`backend/modules/tools/setup.py`

`register_all_tools()` 函数按顺序注册所有工具：

```python
def register_all_tools(workspace, command_timeout=30, ...):
    tools = ToolRegistry()

    # 1. 文件系统工具（AI 可用，前端隐藏）
    tools.register(ReadFileTool(workspace, ...))
    tools.register(WriteFileTool(workspace, ...))
    tools.register(EditFileTool(workspace, ...))
    tools.register(ListDirTool(workspace, ...))

    # 2. Shell 工具（AI 可用，前端隐藏）
    tools.register(ExecTool(workspace, timeout, ...))

    # 3. Web 工具（可见）
    tools.register(WebFetchTool())

    # 4. Spawn 工具（如果有 SubagentManager）
    if subagent_manager:
        tools.register(SpawnTool(subagent_manager))

    # 5. 发送媒体工具（如果有 ChannelManager）
    if channel_manager:
        tools.register(SendMediaTool(channel_manager, ...))

    # 6. 截图工具
    tools.register(ScreenshotTool(workspace))

    # 7. 文件搜索工具
    tools.register(FileSearchTool(default_max_results=20))

    # 8. 记忆工具（如果有 MemoryStore）
    if memory_store:
        tools.register(MemoryWriteTool(memory_store))
        tools.register(MemorySearchTool(memory_store))
        tools.register(MemoryReadTool(memory_store))

    return tools
```

注意条件注册：某些工具只在对应组件存在时才注册（如 spawn 需要 SubagentManager）。

## 5、内置工具详解

### （1）文件系统工具

| 工具名 | 功能 | 前端可见 |
|--------|------|----------|
| `read_file` | 读取文件/目录，支持行号范围、多文件批量读取 | 隐藏 |
| `write_file` | 写入文件，支持追加模式 | 隐藏 |
| `edit_file` | 编辑文件，支持行号替换和文本匹配替换 | 隐藏 |
| `list_dir` | 列出目录内容 | 隐藏 |

文件系统工具有**工作区限制**（`restrict_to_workspace`），防止 AI 访问工作区外的文件。

### （2）Shell 工具

```
exec_command - 执行 Shell 命令
├── 安全特性：
│   ├── 危险命令拦截（rm -rf、format 等）
│   ├── 工作区限制（可选）
│   ├── 命令白名单/黑名单
│   ├── 输出截断（最大 10K 字符）
│   └── 超时保护（默认 30 秒）
├── 审计：
│   └── 记录所有命令执行到审计日志
└── 参数：
    ├── command: 要执行的命令
    └── working_directory: 工作目录（可选）
```

### （3）Web 工具

```
web_fetch - 获取网页内容
├── 使用 trafilatura 提取正文
├── 自动过滤 HTML 标签
└── 返回纯文本内容
```

### （4）记忆工具

```
memory_write  - 写入记忆（追加一条记录）
memory_search - 搜索记忆（关键词匹配）
memory_read   - 读取记忆（按行号或全部）
```

### （5）其他工具

```
spawn          - 创建子代理处理后台任务
send_media     - 向指定渠道发送消息/媒体
screenshot     - 截取屏幕截图
file_search    - 在文件系统中搜索文件
```

## 6、工具调用通知

当工具被执行时，系统会通过 WebSocket 通知前端：

```python
# loop.py:196-204
# 工具调用开始通知
await notify_tool_execution(
    session_id=session_id,
    tool_name=tool_name,
    arguments=tool_args,
)

# 工具执行完成通知（含结果）
await notify_tool_execution(
    session_id=session_id,
    tool_name=tool_name,
    arguments=tool_args,
    result=result,  # 或 error=error_msg
)
```

前端可以根据这些通知展示工具调用的实时状态。

## 7、审计日志系统

每个工具调用都会被记录到审计日志：

```
文件审计日志 (file_audit_logger)
├── record_call()      - 记录工具调用开始
├── update_result()    - 更新执行结果
└── record_ai_response() - 记录 AI 完整响应
```

审计日志的用途：
- 追溯 AI 的操作历史
- 排查异常行为
- 安全审计

## 8、如何开发自定义工具

开发一个新工具需要以下步骤：

```python
# 1. 继承 Tool 基类
from backend.modules.tools.base import Tool

class MyCustomTool(Tool):

    @property
    def name(self) -> str:
        return "my_tool"

    @property
    def description(self) -> str:
        return "我的自定义工具，用于..."

    @property
    def parameters(self) -> dict:
        return {
            "type": "object",
            "properties": {
                "input_text": {
                    "type": "string",
                    "description": "输入文本"
                }
            },
            "required": ["input_text"]
        }

    async def execute(self, input_text: str, **kwargs) -> str:
        # 实现工具逻辑
        result = f"处理结果: {input_text}"
        return result

# 2. 在 setup.py 中注册
tools.register(MyCustomTool())
```
