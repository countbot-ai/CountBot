# IPv4 与 IPv6 地址

## 1、基本概念

IP 地址是网络中设备的"门牌号"，目前有两个版本：

| | IPv4 | IPv6 |
|---|------|------|
| 格式 | `192.168.1.1` | `2001:0db8:85a3::8a2e:0370:7334` |
| 长度 | 32 位 | 128 位 |
| 地址数量 | 约 43 亿 | 几乎无限 |

## 2、特殊地址对照

| 含义 | IPv4 | IPv6 |
|------|------|------|
| 所有地址（监听所有网卡） | `0.0.0.0` | `::` |
| 本地回环（只有本机能访问） | `127.0.0.1` | `::1` |

## 3、在 Web 服务中的含义

当启动一个 Web 服务器时，`host` 参数决定了谁能访问：

```python
# 只有本机能访问 —— 安全，适合开发
uvicorn.run(app, host="127.0.0.1", port=8000)

# 所有设备都能访问 —— 局域网其他设备也能访问
uvicorn.run(app, host="0.0.0.0", port=8000)
```

### （1）举例

假设你的电脑局域网 IP 是 `192.168.1.100`：

| host 设置 | 本机访问 localhost:8000 | 其他设备访问 192.168.1.100:8000 |
|-----------|----------------------|-------------------------------|
| `127.0.0.1` | 可以 | 不可以 |
| `0.0.0.0` | 可以 | 可以 |

## 4、本项目中的用法

```python
if host in ["0.0.0.0", "::"]:
    # 监听了所有接口，显示局域网 IP 供其他设备访问
    for ip in local_ips:
        logger.info(f"Network: http://{ip}:{port}")
```

同时检查 `0.0.0.0` 和 `::`，是为了兼顾用户可能设置 IPv4 或 IPv6 地址的情况。
